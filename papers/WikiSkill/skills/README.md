# WikiSkill skills

Empty on purpose. WikiSkill initialises the skill set and the wiki to nothing
(S0 = ∅, W0 = ∅; Algorithm 1) for every benchmark and every compared method. The
evolved skills are not released. The paper's Table 4 reports their size, for example
1.4 accepted skills of 142.5 lines on SpreadsheetBench.

To run our pipeline under WikiSkill's protocol, use an empty base skill. To compare at
equal starting points with SkillOpt, use `../../SkillOpt/skills/initial/`.
