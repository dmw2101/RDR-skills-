# Telecom support procedures

`initial.md` is the **exact default agent policy** from tau2-bench `v1.0.1`:
`main_policy.md` followed by `tech_support_manual.md`, with the same XML wrappers
used by the official `get_environment()` function. No instructions were rewritten
or generated by an LLM. See `source.json` for source paths and checksums, and
`LICENSE.txt` for the upstream MIT license.

Size: **3,715 whitespace-separated words**, including the four XML wrapper tags
(23,318 characters). These are not model-token counts.

It covers customer identification, overdue bills, suspension, data refueling,
plan changes, roaming, cellular service, mobile data, and MMS troubleshooting.
Some procedures depend on others: MMS needs working service and mobile data;
data problems can require billing, suspension, roaming, or refueling guidance.
A reduced view must retain applicable prerequisites and general constraints.

The alternate workflow and solo-agent policies are **not** added to this skill.
They remain in the downloaded benchmark for inspection.

Status: source skill imported; feature schema, reviewed IR, compiled MCRDR tree,
and Telecom full/reduced/no-skill evaluation integration are not yet implemented.
The existing Gemini extraction command therefore is not ready for this skill yet.

See [benchmark setup and integration scope](../../benchmarks/telecom/README.md).
